## Deliver checklist (from the task card)
- [x] `backend/app/api/documents.py`: POST /v1/documents endpoint implementing SPEC §3 and contracts/openapi.yaml.
  - JWT auth required (`sub` -> `employee_id`); returns 401 without token.
  - Body validated against `DocumentCreate` (Pydantic); returns 422 `VALIDATION_FAILED` on invalid input.
  - Idempotency per employee by sha256: repeat call returns 200 with existing `document_id`, `claim_id`, `line_id` and zero new rows.
  - On new sha256 (201): attaches to employee's open draft claim (creates one if none exists); stores document metadata (`sha256`, `mime`, `pages`, `capture_source`, `device_tier`, `prompt_version`).
  - Path 1 (extraction provided): validates `ExtractedReceipt`, immediately stores `extracted_fields` (source `ocr`/`llm`) and `expense_lines` (category, vendor, amount_paise, date, GSTIN, taxes), returns `status="extracted"`.
  - Path 2 (extraction null with ocr_text): enqueues RQ job on `${QUEUE_PREFIX}extract`, returns `status="queued"`.
- [x] `backend/app/services/extraction.py`:
  - `save_extracted_receipt()`: takes parsed `ExtractedReceipt`, creates `expense_lines` row, populates `extracted_fields`, runs GSTIN checksum & tax math validations, updates claim total.
  - `parse_ocr_heuristics(ocr_text)`: pre-fills vendor, date, and total from regex heuristics on raw OCR text.
  - `run_degraded_fallback()`: creates 3 questions (vendor, date, total) with pre-filled candidate values as first option, sets document `needs_confirmation`.
- [x] `backend/app/workers/extract_document.py`:
  - Worker task function `extract_document_task(document_id, ocr_text)`: loads document and OCR text, calls `LLMGateway(mode=settings.LLM_MODE).complete("kh-extract-text", prompt)`.
  - On success: validates JSON with `ExtractedReceipt`, persists line and extracted fields via `save_extracted_receipt()`.
  - Degraded mode on `LLMUnavailable`: sets document status `needs_confirmation`, runs heuristics, and creates 3 confirmation questions.
- [x] `backend/tests/conftest.py`:
  - Session-scoped guard enforces `TEST_DATABASE_URL` (`kharcha_test`).
  - Redis guard ensures `QUEUE_PREFIX` in tests uses a test prefix (e.g. `test-`) and does not write to dev queues.
- [x] `backend/tests/test_documents.py`:
  - Path 1 stores fields and line immediately with expected values.
  - Idempotency: same sha256 returns 200 and identical IDs without adding rows.
  - Different employee with same sha256 creates a separate document.
  - Path 2 in stub mode: synchronous execution of worker job fills fields and expense line.
  - Degraded mode: mock `LLMUnavailable` creates `needs_confirmation` and 3 confirmation questions with prefilled options.
  - Auth checks: 401 missing token, 422 invalid payload.
- [x] `backend/tests/test_contract.py`:
  - Update `UNBUILT_PATHS` by removing `/v1/documents` and ensuring full contract coverage passes against `contracts/openapi.yaml`.
