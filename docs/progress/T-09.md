## Decisions
- Tasks communicate exclusively via task aliases defined in `gateway/litellm.config.yaml` (`kh-extract-image`, `kh-extract-text`, `kh-agent`, `kh-parse`).
- In stub mode (`LLM_MODE=stub`), responses are served from `tests/fixtures/llm/<alias>/` to ensure 0 external network traffic in test suites.
- When live LLM is requested, timeout limits are enforced at client level matching SPEC §6: 20s for extraction, 8s for agent, 5s for parse.
- Any unrecoverable LLM failure raises `LLMUnavailable`, allowing downstream workflows to enter degraded mode.
