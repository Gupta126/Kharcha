## Decisions
- `schemas/receipt.py` uses Pydantic v2 with `extra="forbid"` to mirror JSON schema's `additionalProperties: false`.
- `validators.py` implements SPEC §5 exact rules:
  - GSTIN: regex `^[0-3][0-9][A-Z]{5}[0-9]{4}[A-Z][1-9A-Z]Z[0-9A-Z]$`, state code 01-38, mod 36 checksum.
  - Tax math: result codes `ok`, `cgst_sgst_mismatch`, `mixed_igst_cgst`, `total_mismatch`, `rate_not_slab`.
  - Date sanity: not in the future (reference date + 1 day), older than 60 days flagged red.
  - Amount normaliser: converts various rupee inputs (string, float, int) to integer paise.
  - Vendor canonicaliser: strips legal suffixes, normalises casing and whitespace, cleans punctuation.
- Test suite loads vectors dynamically from `contracts/test-vectors/` without duplication.
